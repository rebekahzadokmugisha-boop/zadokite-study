# Zadokite Study

The Zadokite family study tool: each child's own world of quests and games, and a parents' dashboard behind a PIN.

Opens at https://rebekahzadokmugisha-boop.github.io/zadokite-study/ and installs to any phone, tablet or laptop as an app. Sign-in and progress are kept in Firebase (project `house-of-israel`, collections `zadokite_attempts` and `zadokite`).
